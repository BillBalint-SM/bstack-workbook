# UI plan review dimensions

- Information architecture: first/next action, hierarchy and navigation.
- Interaction states: loading, empty, error, success, partial and disabled
  states as applicable; say what the user sees and how they recover.
- Journey: entry, key task, feedback and exit; separate a hypothesized reaction
  from actual user research.
- Visual specificity: concrete decisions serving this surface, no boilerplate
  marketing sections, false metrics or style bans overriding approved choices.
- System alignment: typography, color, spacing, components and state tokens.
- Responsive/accessibility: 320px, keyboard, labels, focus order, readable
  contrast, zoom and reduced motion where relevant.
- Open decisions: distinguish accepted design choices from proposed options.

A deeper review can include a state matrix, journey map, grounded scorecard,
mockups and implementation tasks. It must not automatically edit the plan,
force every dimension to 10/10 or launch external model reviews.
