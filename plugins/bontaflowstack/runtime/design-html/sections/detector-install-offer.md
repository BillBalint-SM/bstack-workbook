# Optional design detector

Use an already available, authorized detector only when its result helps this
request. The packaged design detector may report unavailable on Windows; that
is not authorization to download a binary, modify global configuration or
switch hosts. Follow HOST.md. Do not offer installation on every design run.

Use actual scan output with its tool/rule identifiers. A missing optional scan
is NOT_RUN, while a required unavailable check is BLOCKED. Review the design
visually either way when the browser is available. A detector score alone is
not design approval.
